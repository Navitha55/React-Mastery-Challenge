# ⚛️ React Mastery Challenge

A hands-on React learning journey where I built multiple mini projects to practice core React concepts, hooks, state management, API integration, and modern React development.

## 📚 Projects

| Day   | Project                 | Key Concepts                                                                 |
| ----- | ----------------------- | ---------------------------------------------------------------------------- |
| Day 1 | User Profile Card       | Components, Props, State, Event Handling                                     |
| Day 2 | User Registration Form  | Forms, Validation, Lists & Keys, useRef, props.children                      |
| Day 3 | Notification & Settings | Portals, Context API, Error Boundaries, Controlled & Uncontrolled Components |
| Day 4 | To Do List              | State Management, CRUD Operations, Conditional Rendering                     |
| Day 5 | User Directory          | API Fetching, Axios, Fetch, Search, Dynamic UI                               |
| Day 6 | Cart Manager            | useReducer, Actions, Reducers, Cart State Management                         |
| Day 7 | Shopping Cart           | useState, Props, Component Composition                                       |
| Day 8 | Stop Watch              | useState, useRef, Timers                                                     |
